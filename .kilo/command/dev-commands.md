# Type Check
Check TypeScript for type errors

```bash
npm run type-check
```

# Lint Check
Run ESLint to check for code quality issues

```bash
npm run lint
```

# Lint Fix
Fix auto-fixable ESLint issues

```bash
npm run lint:fix
```

# Test
Run unit tests

```bash
npm test
```

# Test Watch
Run tests in watch mode

```bash
npm run test:watch
```

# Start Dev
Start the Expo development server

```bash
npm start
```
